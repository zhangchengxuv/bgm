你好！我是 **Zhang Chenxu**，这里是我的个人综合博客 **世界线观测站（zhangchenxu.uk）**。

## 这里记录什么？

- **技术笔记与折腾记录**：云服务器、网络架构、自动化工作流与开发工具实践。
- **书影音收藏馆**：与我的 [Bangumi](https://bgm.tv/user/829882) 账号联动，每日自动同步我看过的动画、读过的书籍和玩过的游戏。
- **开源与代码足迹**：自动同步 [GitHub (@zhangchengxuv)](https://github.com/zhangchengxuv) 的公开提交与贡献统计。

## 本站技术栈

- **框架**：Hexo + 自定义 Stargazer 深空玻璃主题（支持深/浅双色模式）
- **数据同步**：GitHub Actions 每日定时拉取 Bangumi 收藏、封面镜像与 GitHub 活动
- **部署与加速**：GitHub Pages + Cloudflare 全球边缘 CDN 缓存
